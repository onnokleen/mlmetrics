12 Gradient Boosting

12.1 Overview

Gradient boosting is a sequential tree-based method that builds an additive predictor by repeatedly fitting new trees to the mistakes of the current ensemble. Random forests are designed primarily to stabilize high-variance trees through averaging, whereas boosting often emphasizes bias reduction through successive corrections. In practice, both methods can change both bias and variance. The modern gradient-boosting formulation is due to J. H. Friedman (2001); adaptive boosting (AdaBoost) is an important predecessor and special case in the broader boosting literature (Freund and Schapire 1997).

For econometricians, boosting is a flexible predictive tool for tabular data. It can learn nonlinearities, interactions, threshold effects, and asymmetric predictive relationships without the researcher specifying them. It is well suited to settings where the signal is spread across many variables: representing such structure with one regularized tree may require many splits and produce an unstable approximation.

At the same time, boosting has several interacting tuning choices. Learning rate, tree depth, early stopping—halting the boosting run at the iteration count that performs best on held-out data—and validation design are all consequential. In time-series and forecasting applications, careless validation can create large but spurious performance gains. A common credit-default application near the end of the chapter compares boosting with a single tree, a random forest, logistic regression, and a feed-forward neural network (FNN) using the same data split and the same probability-based scores.

12.2 Roadmap

  1. We begin with the additive structure of boosting and contrast it with random forests.
  2. We then derive the squared-error version, where each new tree fits residuals.
  3. Next we generalize to arbitrary differentiable losses, with each new tree fitted to the negative loss gradients—the pseudo-residuals.
  4. We then discuss shrinkage (scaling each tree’s contribution by a learning rate), tree depth, subsampling, and early stopping.
  5. We then revisit credit-card default prediction to compare the tree-based methods with logistic regression and a feed-forward neural network.
  6. Finally, we summarize how boosting should be interpreted and validated in econometric applications.

12.3 Additive Stagewise Modeling

Following the standard notation in the boosting literature, this chapter writes \hat F_m for the fitted ensemble prediction function after iteration m and F for a generic candidate function. This chapter-local notation is distinct from the use of F for a predictive cumulative distribution function in earlier chapters. In regression, \hat F_m(x) is a point prediction; in binary classification below, it is the log-odds of the event.

Boosting constructs the predictor

\hat F_M(x) = \hat F_0(x) + \nu \sum_{m=1}^M \hat h_m(x),

where:

  • \hat F_0 is an initial simple predictor
  • \hat h_m is the tree added at iteration m
  • \nu \in (0,1] is the learning rate—the boosting counterpart of the gradient-descent step size \eta in the optimization chapter; the symbol \nu follows the boosting literature and is unrelated to the degrees-of-freedom parameter of the distributional network chapter
  • M is the number of boosting iterations

Each tree here plays the role of a weak learner (equivalently, a base learner): a deliberately low-complexity base model—in this chapter a shallow regression tree. The name comes from classification boosting, where a weak learner performs only slightly better than random guessing. Gradient boosting imposes no such requirement on any tree in isolation. Each tree’s job is instead to move the current ensemble in a descent direction of the loss, so it is fitted to the current residuals or pseudo-residuals rather than directly to the original target.

Random Forests vs Boosting

The two methods use the same basic building block, the decision tree, but in different ways:

  1. Random forests grow many trees largely independently and average them, primarily to stabilize high-variance tree predictions.
  2. Boosting grows trees sequentially, with each new tree correcting the current ensemble; this often reduces bias, but can also change variance.
  3. Random forests do not have a learning-rate–iteration-count tradeoff; boosting requires these two choices to be tuned jointly.

12.4 Squared-Error Boosting

Start with regression. The training sample is \{(x_i, y_i)\}_{i=1}^N, with predictor vector x_i \in \mathbb{R}^p and scalar outcome y_i—in the book’s case convention, the realized values of random pairs (X_i, Y_i), as in the decision trees chapter. Under squared loss, the training objective of a candidate prediction function F is

L(F) = \frac{1}{2}\sum_{i=1}^N (y_i - F(x_i))^2.

The factor \frac{1}{2} is algebraically convenient and does not affect the minimizer.

Two conventions in this display are worth flagging, since they differ from earlier chapters. First, L here is the total training loss, summed and not averaged over observations—the convention of the boosting literature, and the one that makes the pseudo-residuals below come out as y_i - F(x_i) without a trailing 1/N. The optimization chapter instead wrote L(\boldsymbol\theta) = N^{-1}\sum_{i=1}^N \ell_i(\boldsymbol\theta) for the sample average; the two differ by the constant factor N, which changes neither the minimizer nor the direction of the gradient. Second, the per-observation loss is written outcome first, \ell(y_i, F(x_i)), as in the feed-forward networks chapter.

Step 0: Initial Model

The best constant predictor minimizes

\frac{1}{2}\sum_{i=1}^N (y_i - c)^2.

Differentiating with respect to c gives

\sum_{i=1}^N (c - y_i) = 0 \quad \Longrightarrow \quad \hat F_0(x) \equiv \bar y.

So the initial model is simply the sample mean.

Step 1: Residual Fitting

At iteration m, define the residuals of the current ensemble as

r_{im} = y_i - \hat F_{m-1}(x_i).

Under squared loss, these residuals are negative derivatives of the loss with respect to the prediction. Hold observation i fixed and regard its loss contribution \tfrac{1}{2}(y_i - z)^2 as an ordinary function of one real argument z, the prediction for that observation. Its derivative is z - y_i, so the negative derivative, evaluated at the current fitted value z = \hat F_{m-1}(x_i), is exactly the residual r_{im}. Boosting therefore fits the next tree \hat h_m(x) to the residuals by least squares. The ideal tree would solve

\min_{h}\ \sum_{i=1}^N \bigl(r_{im} - h(x_i)\bigr)^2,

where the minimization runs over all regression trees h of maximum depth d. Solving this problem exactly is computationally infeasible, so in practice \hat h_m is grown by recursive binary splitting with the residuals as the response. Each split is myopically optimal given the splits already made, so the fitted tree aims at a small value of the least-squares criterion without any guarantee of attaining its global minimum over depth-d trees. One part of the fit is exact, though: given the partition the greedy search selects, the prediction in each leaf is the mean of the residuals in that leaf, which is the least-squares-optimal constant there.

The update is then

\hat F_m(x) = \hat F_{m-1}(x) + \nu \hat h_m(x).

If \nu = 1, the correction is taken in full. If \nu < 1, the update is shrunken.

For an econometrician, this is shrunken forward-stagewise regression. If the candidate weak learners were single regressors rather than trees, each stage would run a low-complexity ordinary least squares regression of the current residuals on the candidate regressors, add only a fraction \nu of the selected fitted value, and then recompute the residuals.

Squared-Error Boosting Algorithm

For the regression-tree case, the algorithm can be summarized as follows.

  1. Initialize \hat F_0(x)=\bar y and residuals r_i=y_i-\bar y.
  2. For m=1,\ldots,M:
    • fit a shallow tree \hat h_m with maximum depth d to the current residuals
    • update \hat F_m(x)=\hat F_{m-1}(x)+\nu \hat h_m(x)
    • update residuals r_i=y_i-\hat F_m(x_i)
  3. Return the boosted predictor \hat F_M(x).

The maximum depth d bounds the interaction order available along a root-to-leaf path, while \nu controls how cautiously each correction is added.

Figure 12.1 follows the fitted function from the initial constant through two later boosting stages. The data are simulated: a single predictor, an outcome that combines a sine wave, a mild linear trend, and an upward level shift beyond x = 0.8, plus Gaussian noise.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.ensemble import GradientBoostingRegressor

rng = np.random.default_rng(202)
x = np.sort(rng.uniform(-3, 3, 200))
y = np.sin(1.3 * x) + 0.35 * x + 0.8 * (x > 0.8) + rng.normal(scale=0.35, size=x.shape[0])

gbr = GradientBoostingRegressor(
    n_estimators=60,
    learning_rate=0.1,
    max_depth=2,
    min_samples_leaf=8,
    random_state=202,
)
gbr.fit(x.reshape(-1, 1), y)

x_grid = np.linspace(-3.1, 3.1, 500)
staged = list(gbr.staged_predict(x_grid.reshape(-1, 1)))
f0 = np.full_like(x_grid, np.mean(y))

fig, axes = plt.subplots(1, 3, figsize=(13, 4.5), sharey=True)

for ax, pred, title in zip(
    axes,

):

The ensemble starts as a constant. With each iteration, the fit becomes more refined because the next tree is trained on what the current ensemble still gets wrong.

Why Small Trees Are Used

Boosting usually uses shallow trees rather than deep ones. A decision stump is a depth-1 tree with one split, so it captures a single threshold effect. A tree of depth 2 or 3 can capture low-order interactions. This is deliberate regularization:

  • shallow trees make each correction simple
  • many simple corrections can approximate a complicated function
  • restricting tree depth reduces the risk of overfitting each stage

This stagewise logic is one reason boosting performs well on tabular data when the regression function has low- to moderate-order interactions.

12.5 General Gradient Boosting

Gradient boosting extends beyond squared loss by replacing the residual with the negative gradient of a differentiable loss. Suppose the objective is

\sum_{i=1}^N \ell(y_i, F(x_i)),

where \ell is differentiable with respect to the fitted value F(x_i).

Before the stagewise updates begin, choose the loss-optimal constant predictor

\hat F_0(x)\equiv\hat\gamma_0, \qquad \hat\gamma_0 \in \arg\min_{\gamma\in\mathbb{R}} \sum_{i=1}^N \ell(y_i,\gamma).

Under squared loss this constant is the sample mean; under the Bernoulli log-loss introduced below for classification, it is the sample log-odds when both classes occur. The membership symbol \in allows for losses whose sample minimizer is not unique—under absolute-error loss, for example, every value between the two middle observations of an even-sized sample minimizes.

At iteration m, the pseudo-residual is defined exactly as in the squared-error case: hold y_i fixed, regard \ell(y_i, z) as a function of the scalar prediction z, differentiate, and evaluate at the current fitted value:

r_{im} = - \left. \frac{\partial \ell(y_i, z)}{\partial z} \right|_{z=\hat F_{m-1}(x_i)}.

No derivative with respect to a function is involved: \hat F_{m-1}(x_i) is a number, and r_{im} is positive exactly when raising the prediction for observation i would lower its loss.

The next tree is fitted to these pseudo-residuals, giving a tree approximation to the negative-gradient direction. That is why the method is called gradient boosting. For a general loss, distinguish three steps:

  1. compute the pseudo-residuals,
  2. use them to choose the tree’s splits, and
  3. choose the leaf corrections for the original loss before applying shrinkage.

We make the last step explicit below. The loss also fixes the statistical target: in population, the ideal predictor minimizes the risk \mathbb{E}[\ell(Y, F(X))] over the random pair (X,Y), so changing the loss changes what the ensemble estimates.

Refining the leaf values. The least-squares tree fitted to the pseudo-residuals is used only for its partition of the predictor space into leaves R_{jm}, j=1,\dots,J_m, written as in the decision-tree chapter but now indexed by the iteration m. Its leaf means average the pseudo-residuals, and such an average need not be the step that minimizes the original loss within the leaf. Each leaf value is therefore replaced by the solution of a one-dimensional minimization, the per-leaf line search of J. H. Friedman (2001), provided a finite minimizer exists:

\gamma_{jm}^{\star} \in \arg\min_{\gamma} \sum_{i:\, x_i \in R_{jm}} \ell\big(y_i,\, \hat F_{m-1}(x_i) + \gamma\big).

For squared error, \gamma_{jm}^{\star} is again the mean residual in the leaf, so nothing changes; for the Bernoulli loss introduced next, it differs. The tree added at iteration m combines the partition from the pseudo-residual fit with these leaf values,

\hat h_m(x) = \sum_{j=1}^{J_m} \gamma_{jm}^{\star}\,\mathbf{1}\{x \in R_{jm}\},

so the update is still \hat F_m=\hat F_{m-1}+\nu\hat h_m: every x in leaf R_{jm} has its fitted value moved by \nu\gamma_{jm}^{\star}.

Classification with Bernoulli Log-Loss

For binary outcomes y_i\in\{0,1\}, let F(x_i)\in\mathbb{R} denote the ensemble’s real-valued output. The sigmoid function converts this output into an event probability:

p_i = \sigma(F(x_i)) = \frac{1}{1 + e^{-F(x_i)}}.

For any probability p_i\in(0,1), the odds of the event are p_i/(1-p_i). The log-odds, also called the logit, are the logarithm of those odds. Because the logit is the inverse of the sigmoid,

F(x_i) = \log\left(\frac{p_i}{1-p_i}\right).

Thus F(x_i) is the log-odds of the event rather than a probability, and for Bernoulli boosting we refer to it simply as the log-odds. It can take any real value, while the sigmoid maps it into a probability between zero and one. The same sigmoid link appears in a logit model, where the linear index x_i'\beta plays the role of the sum of trees. Adding one unit to F(x_i) multiplies the event odds by e; it does not add a fixed amount to the probability. The Bernoulli log-loss is

\ell(y_i, F(x_i)) = - y_i \log p_i - (1-y_i)\log(1-p_i).

Differentiating in the log-odds argument z, with p = \sigma(z), gives

\frac{\partial \ell(y_i, z)}{\partial z} = \sigma(z) - y_i.

At boosting iteration m this derivative is evaluated at the current log-odds z = \hat F_{m-1}(x_i), so write p_{i,m-1} = \sigma(\hat F_{m-1}(x_i)) for the fitted probability that observation i carries into iteration m. The probability changes at every iteration, and the subscript keeps that visible. The negative gradient is then

r_{im} = y_i - p_{i,m-1}.

Classification boosting therefore retains a residual-like target, y_i-p_{i,m-1}, formed from the binary outcome and the current probability. The fitted value \hat F_{m-1}(x_i), however, lives on the log-odds scale. The Newton leaf calculation below uses Bernoulli curvature to translate the probability-scale discrepancy into an update of the log-odds.

For the Bernoulli loss, the per-leaf line search for \gamma_{jm}^{\star} has no closed form in general. A finite minimizer exists when both classes occur in the leaf; in an all-one or all-zero leaf, the loss instead approaches its infimum as \gamma\to+\infty or \gamma\to-\infty, respectively. Implementations commonly use one finite Newton step from \gamma=0 rather than solve the leaf problem exactly,

\widetilde\gamma_{jm} = \frac{\sum_{i:\, x_i \in R_{jm}} (y_i - p_{i,m-1})}{\sum_{i:\, x_i \in R_{jm}} p_{i,m-1}(1-p_{i,m-1})},

using the gradient p_{i,m-1} - y_i and the curvature p_{i,m-1}(1-p_{i,m-1}) evaluated at the probabilities carried in from iteration m-1. The tilde distinguishes this one-step update from an exact minimizer \gamma_{jm}^{\star} when one exists; when the one-step value is used, \widetilde\gamma_{jm} takes the place of \gamma_{jm}^{\star} as the leaf value in \hat h_m. The new probability is p_{im}=\sigma(\hat F_{m-1}(x_i)+\nu\widetilde\gamma_{jm}) for x_i\in R_{jm}; the leaf correction is added to the log-odds, not directly to p_{i,m-1}. Because it is a single step rather than a solved minimization, \widetilde\gamma_{jm} can overshoot the loss-optimal leaf value, and on its own it is not guaranteed to lower the leaf’s loss; shrinking the correction by \nu tempers exactly this risk.

The scaling becomes important when the current probabilities are extreme. The curvature contribution p_{i,m-1}(1-p_{i,m-1}) is close to zero when p_{i,m-1} is close to zero or one. If such an extreme prediction is wrong, the corresponding residual y_i-p_{i,m-1} is instead close to 1 or -1. A leaf containing this confidently misclassified observation can therefore have a non-negligible numerator but little total curvature in the denominator, producing a large correction on the log-odds scale.

The denominator is also the observed Fisher curvature for a one-parameter Bernoulli log-odds model within the leaf. Thus the Newton leaf update is a local Fisher-scoring step: it divides the leaf’s summed log-likelihood gradient \sum_{i:\,x_i\in R_{jm}}(y_i-p_{i,m-1})—the score of that Bernoulli model, evaluated at \gamma=0—by the amount of statistical curvature in that leaf. The natural-gradient section of Chapter 13 generalizes the same information-scaling idea to a vector of distribution parameters.

Connection to Cross-Entropy

For classification, boosting with Bernoulli log-loss is minimizing cross-entropy, i.e., the negative log-likelihood of a Bernoulli model. The equivalence links boosting directly to the maximum-likelihood and Kullback–Leibler discussion: fitting the boosted classifier means reducing the discrepancy between observed class outcomes and predicted event probabilities.

AdaBoost as Exponential-Loss Boosting

AdaBoost predates gradient boosting, but exponential loss places the two algorithms in a common framework. Freund and Schapire (1997) introduced AdaBoost. J. Friedman, Hastie, and Tibshirani (2000) later connected its observation-weighting rule to exponential-loss boosting and interpreted the resulting additive model as additive logistic regression.

For binary classification with y_i \in \{-1, +1\} for i=1,\ldots,N, define

\ell(y_i, F(x_i)) = e^{-y_i F(x_i)}.

The label coding and the scale of F now differ from the Bernoulli section. If p(x)=\mathbb{P}(Y=+1\mid X=x)\in(0,1), minimizing p(x)e^{-F}+(1-p(x))e^F gives F=\tfrac12\log[p(x)/(1-p(x))], half the log-odds. The corresponding probability map is therefore \sigma(2F), whereas the Bernoulli section above uses \sigma(F).

The negative gradient at the current fit is

r_{im} = -\left.\frac{\partial \ell(y_i, z)}{\partial z}\right|_{z=\hat F_{m-1}(x_i)} = y_i \, e^{-y_i \hat F_{m-1}(x_i)}.

Weighted-classification equivalence. Define the observation weight

w_{im}=e^{-y_i\hat F_{m-1}(x_i)},

so that r_{im}=y_iw_{im}. Suppose the weak learner is a classifier with h(x_i)\in\{-1,+1\}. Because h(x_i)^2=1, its least-squares criterion satisfies

\sum_{i=1}^N\bigl(r_{im}-h(x_i)\bigr)^2 = C_m-2\sum_{i=1}^N w_{im}y_i h(x_i), \qquad C_m=\sum_{i=1}^N\bigl(w_{im}^2+1\bigr).

The constant C_m does not depend on h. Moreover,

\mathbf{1}\{y_i\neq h(x_i)\} = \frac{1-y_i h(x_i)}{2}.

Minimizing the least-squares criterion is therefore equivalent to minimizing weighted misclassification error. This equivalence relies on the restriction h(x_i)\in\{-1,+1\}; it does not apply to the real-valued regression-tree leaves used elsewhere in this chapter.

The signed margin of observation i is y_i\hat F_{m-1}(x_i). A negative margin indicates misclassification and implies w_{im}>1, so the next classifier places more weight on the current mistakes. This is the AdaBoost observation-reweighting step. Write \hat g_m(x)\in\{-1,+1\} for the selected classifier, before scaling its contribution to the ensemble. The full AdaBoost algorithm also chooses

\alpha_m = \frac{1}{2}\log\!\left(\frac{1-\mathrm{err}_m}{\mathrm{err}_m}\right),

where \mathrm{err}_m=\sum_i w_{im}\mathbf{1}\{y_i\ne\hat g_m(x_i)\}/\sum_i w_{im} is the fitted weak classifier’s weighted misclassification rate. The unshrunk update is \hat F_m=\hat F_{m-1}+\alpha_m\hat g_m. A finite positive step requires 0<\mathrm{err}_m<1/2; error 1/2 gives zero weight, while a perfect classifier requires a stopping or finite-step convention. This step size is itself exponential-loss optimal: minimizing \sum_i w_{im}e^{-\alpha y_i\hat g_m(x_i)}=e^{-\alpha}\sum_{i:\,y_i=\hat g_m(x_i)}w_{im}+e^{\alpha}\sum_{i:\,y_i\neq\hat g_m(x_i)}w_{im} over \alpha gives e^{2\alpha}=(1-\mathrm{err}_m)/\mathrm{err}_m, which yields the stated value of \alpha_m. AdaBoost is therefore forward-stagewise exponential-loss boosting with a \pm1 base learner and an exact line search (J. Friedman, Hastie, and Tibshirani 2000).

What the Bernoulli residual bound controls. Exponential loss assigns an unbounded weight w_{im} to an observation whose negative margin keeps growing. That observation can eventually dominate the first-order fitting criterion. Returning to 0/1 labels for Bernoulli log-loss, the pseudo-residual satisfies |y_i-p_{i,m-1}|<1. The bound prevents this exponentially increasing first-order contribution at any one iteration.

The bound does not guarantee that the final ensemble is insensitive to one observation. Split selection is discrete: one observation can change which of two similar candidate splits is selected and thereby affect every case routed through that node. The observation also re-enters the fitting problem at each iteration, so its bounded contributions can influence several successive trees.

The pseudo-residual bound also does not bound the approximate Newton leaf value \widetilde\gamma_{jm}. In the Newton update derived above, the denominator is the leaf’s total curvature,

\sum_{i:\,x_i\in R_{jm}}p_{i,m-1}(1-p_{i,m-1}).

The fitting procedure does not guarantee that this sum is bounded away from zero. For a confidently misclassified observation, the numerator contribution approaches 1 or -1, while its curvature contribution approaches zero. The numerator can therefore remain non-negligible when the denominator is small, producing a large leaf update.

Different safeguards address different channels of influence. Minimum leaf sizes discourage splits based on very few observations; a lower bound on total leaf curvature rules out nearly flat leaves; an update cap bounds |\widetilde\gamma_{jm}| directly; and penalties on leaf values shrink the update. Log-loss prevents the unbounded per-observation first-order weight generated by exponential loss, but it does not make the fitted ensemble insensitive to individual observations.

12.6 Regularization in Boosting

Boosting can keep refining the fit indefinitely. That is why regularization is essential, not optional.

Learning Rate

The learning rate \nu shrinks each update:

\hat F_m(x) = \hat F_{m-1}(x) + \nu \hat h_m(x).

Smaller \nu means:

  • slower learning
  • more trees needed
  • often better generalization, because the fit evolves more cautiously

Scaling each update by \nu<1 is called shrinkage. Along the training-risk path, the interaction between \nu and M is roughly reciprocal: a smaller \nu requires correspondingly more iterations to reach the same training risk, so as a heuristic, halving \nu roughly doubles the number of trees needed. The validation-optimal M is a different matter—if small-\nu paths merely retraced the same fits more slowly, shrinkage could not improve generalization. What J. H. Friedman (2001) reports empirically is the qualitative pattern: smaller \nu tends to deliver better test error and requires a correspondingly larger M; this is a rule of thumb, not a theorem. Zhang and Yu (2005) supply theoretical support for treating the iteration count as a regularization device.

Number of Trees

The number of iterations M controls how long the algorithm keeps refining the fit.

  • too few trees can underfit
  • too many trees can eventually overfit
  • the optimal M is usually chosen by validation or early stopping—that is, by stopping boosting at the iteration where validation error is minimized (see Section 12.7)

Tree Depth

Depth controls the maximum interaction order available along a root-to-leaf path.

  • depth 1: additive threshold effects only
  • depth 2: two-way interactions can appear, but need not
  • deeper trees: higher-order local interactions are permitted, but repeated variables or additive structure can keep the realized interaction order lower

Subsampling

Some boosting implementations fit each new tree on a random subsample of the data rather than the full sample. This is called stochastic gradient boosting (J. H. Friedman 2002).

Subsampling can reduce variance and speed computation by making each stage cheaper and less tied to one full-sample pseudo-residual fit. It introduces additional randomness into the stagewise updates, so any predictive benefit must be checked over repeated seeds and with the appropriate validation design.

Monotonicity Constraints

Sometimes the econometrician has credible prior knowledge about the sign of a predictive relationship even if the rest of the conditional mean is complicated. For example, one might regard it as implausible that a higher debt-service burden should lower predicted default risk, or that a tighter financial-conditions index should lower predicted recession risk, all else equal. A monotonicity constraint imposes exactly such a shape restriction on the fitted function.

In a tree-ensemble model, this means restricting the fitted prediction to move only in one direction as a chosen predictor increases, holding the other predictors fixed. The idea is not unique to boosting, but it is especially prominent in modern boosted-tree implementations because it fits naturally into the broader regularization toolkit. This does not make the model structural or causal. It is better understood as a regularization device that uses economic theory to rule out locally implausible wiggles in the prediction surface.

When the sign restriction is well founded, monotonicity constraints can improve credibility, stabilize partial-effect summaries, and prevent the ensemble from fitting noise in directions that contradict economic reasoning. But they are not free. If the true conditional relationship is non-monotone, changes sign across regimes, or is only monotone after conditioning on variables the model does not include, the constraint can introduce systematic misspecification.

How the constraint is enforced. A monotonicity constraint is a hard restriction on the fitted function, not a penalty added to the loss. The mechanism is the one described in the random-forests chapter: candidate splits that would violate the requested ordering are rejected, and bounds on leaf values are propagated down the tree. In boosting, each successive tree is constrained in this way, so the accumulated sum of trees respects the ordering as well.

In scikit-learn. The histogram-based gradient-boosting estimator HistGradientBoostingRegressor accepts a monotonic_cst argument with one integer per feature: +1 for increasing, -1 for decreasing, and 0 for no constraint. For three predictors, with the first constrained to have a monotonically increasing effect:

from sklearn.ensemble import HistGradientBoostingRegressor

model = HistGradientBoostingRegressor(
    monotonic_cst=[1, 0, 0],
    max_iter=500,
    learning_rate=0.05,
)

Implementation Note: Extreme Gradient Boosting (XGBoost)

Extreme gradient boosting (XGBoost) (Chen and Guestrin 2016) is an optimized implementation family for gradient-boosted trees. Relative to the basic algorithm in this chapter, it adds engineering and regularization features such as efficient split search, \ell_1 and \ell_2 penalties, sparse or missing-value handling, monotone constraints, and scalable training. The econometric interpretation remains the same: it is still a tuned predictive tree ensemble, so validation design and the information set are central.

The vertical axis is logarithmic, so proportional changes are equally visible everywhere and the behavior near the validation minimum is not compressed by the large initial errors. Because the held-out sample is inspected at every iteration, it is a tuning sample rather than a final test sample.

Question for Reflection

If two boosted models have similar validation error, what evidence from the validation curve would justify the small-learning-rate, many-tree model, and what evidence would justify the larger-learning-rate, fewer-tree model?

Suggested Answer

A small learning rate with many trees is better supported when its validation curve is flatter near the minimum, making performance less sensitive to the chosen stopping point. A larger learning rate with fewer trees is better supported when it reaches similar validation error with fewer boosting steps and lower computational cost. The immediate deterioration is worth confronting rather than hiding. The lesson of early stopping is not that boosting always improves for a while and then degrades; it is that the iteration count is a regularization dial whose right setting is chosen on held-out data, and here the honest setting is no boosting at all. That zero-tree conclusion is conditional on this split and on keeping the model fitted on the training quarters fixed rather than re-estimating it; a recursive or rolling design that refits at each forecast origin estimates a different deployment risk and could select a different stopping point. The result is not driven solely by the four 2020 outcomes: dropping those validation targets leaves the minimum of both validation curves at zero trees. Those quarters strongly affect the level of the validation MSE—the 2020 contraction and rebound generate residuals of tens of annualized percentage points, and removing those quarters cuts the zero-tree validation MSE by an order of magnitude. Under this fixed-estimation design, these predictors and boosting settings yield no validation gain over the constant. Weak usable signal, instability in the predictive relationship, and estimation error could all contribute; the exclusion check does not distinguish them. In the synthetic example above, the data-generating process is known to be stable and to contain nonlinear signal, and validation error improves substantially on the constant model before flattening out.

12.7 Early Stopping and Validation

Because boosting can continue to improve the training fit for many iterations, some external criterion is needed to decide when to stop. Early stopping uses a validation set or validation path to choose the number of trees, and it is one of the central regularization devices of boosting—not a minor implementation detail.

Econometric Warning

For forecasting applications, early stopping must be based on time-ordered validation data. Random K-fold validation contaminates the forecast-origin information set by allowing later observations into training folds. It can therefore select a materially different stopping point from a real-time design; when future observations reveal useful related structure, it often favors an overly flexible path, but the direction is data-dependent under drift or structural change.

The validation design should mirror the actual forecast exercise:

  • rolling or expanding windows for time series
  • group-aware validation for clustered or panel-style dependence—folds built so that all observations from the same group (borrower, firm, region) stay together
  • leakage-safe preprocessing inside each training fold

Once validation selects the learning rate, depth, and stopping point, assess the chosen procedure on an untouched test sample or a subsequent forecast period. The smallest loss on the tuning path is not an independent estimate of the selected model’s performance.

12.8 Empirical Comparison: Credit-Default Probabilities

The three tree-based chapters introduce a single tree, a random forest, and gradient boosting separately. We can now compare them on one common task. The Taiwan credit-card default data contain records for 30,000 clients, including a binary indicator for default in the month after six months of observed repayment histories (Yeh 2009; Yeh and Lien 2009). The predictors also include the granted credit limit, bill and payment amounts, age, and coded demographic characteristics.

The design exactly reuses the stratified 60% training, 20% validation, and 20% test split from the feed-forward networks chapter. This reuse makes the model scores directly comparable, but it does not create a second independent test of the neural network. The network architecture remains fixed at the eight-unit, one-hidden-layer candidate selected there; we do not alter it after seeing its earlier test result.

The single-tree and random-forest settings are chosen by validation log loss from small candidate sets declared in the code. For boosting, the learning rate and depth come from a small grid, and the number of trees is chosen by early stopping: the validation log loss is tracked from the initial constant prediction through each grid point’s staged predictions, and the iteration with the smallest loss is kept. Exact ties along a path favor fewer trees. If zero trees wins, we retain a constant-probability model and re-estimate its probability on the combined training and validation samples before testing. The iteration count is thus tuned jointly with the learning rate. The comparison uses the same transformed predictors for every model: continuous variables are standardized and categorical variables are one-hot encoded. Standardization helps numerical optimization for logistic regression and the network. It does not change a tree’s available split order because it is a strictly increasing transformation, but using one representation removes an incidental difference between the model pipelines. One consequence of the encoding is not incidental, though: the repayment-status codes are ordered categories (months of payment delay), and one-hot encoding discards the ordering, so no single split can implement a threshold rule such as “delay of two months or more”; the tree-based models must assemble such rules from several level-versus-rest splits. We accept this to keep one representation for all models; an ordinal encoding could well favor the tree-based methods. All transformations are estimated without the test observations.

We evaluate the final probability forecasts by log loss, by the Brier score N_{\mathrm{test}}^{-1}\sum_{i=1}^{N_{\mathrm{test}}}(y_i-\hat p_i)^2, and by accuracy after applying a 0.5 threshold. Log loss and the Brier score evaluate the probabilities themselves; accuracy evaluates one particular binary decision rule.

12.9 Summary

Key Takeaways
  1. Gradient boosting builds an additive ensemble by fitting successive trees to negative loss gradients.
  2. The pseudo-residuals are ordinary residuals under squared loss and y-p under Bernoulli log-loss.
  3. Learning rate, tree count, depth, subsampling, and early stopping control the ensemble complexity.
Common Pitfalls
  • Rapid improvement in training loss does not justify a large learning rate or additional boosting stages.
  • Bernoulli pseudo-residuals are y-p, but leaf corrections are added to the log-odds F, which the sigmoid then converts into a probability.
  • Adding more trees does not give the ensemble an ability to extrapolate smooth trends outside the training support.

Part 1: Initial model, residuals, and the gradient view

The initial model is the sample mean:

Therefore the residuals are

r = (-1.125,\,-0.125,\,-0.625,\,1.875).

These are negative gradients because differentiating the training loss \frac{1}{2}\sum_t (y_{t+1}-F(x_t))^2 with respect to the fitted value F(x_t) gives -(y_{t+1}-F(x_t)); evaluating at the current fit F=\hat F_0 and flipping the sign yields exactly the residual r_{t+1}. Fitting the next stump to the residuals is therefore fitting it to the steepest-descent direction of the training loss.

Part 2: Best first stump

Check the three candidate cutoffs.

For split 1.5:

  • left mean residual: -1.125
  • right mean residual: \frac{-0.125-0.625+1.875}{3}=0.375

Residual SSE:

0 + (-0.125-0.375)^2 + (-0.625-0.375)^2 + (1.875-0.375)^2 = 3.5.

For split 2.5:

  • left mean residual: \frac{-1.125-0.125}{2}=-0.625
  • right mean residual: \frac{-0.625+1.875}{2}=0.625

Residual SSE:

(-1.125+0.625)^2 + (-0.125+0.625)^2 + (-0.625-0.625)^2 + (1.875-0.625)^2 = 3.625.

For split 3.5:

  • left mean residual: \frac{-1.125-0.125-0.625}{3}=-0.625
  • right mean residual: 1.875

Residual SSE:

(-1.125+0.625)^2 + (-0.125+0.625)^2 + (-0.625+0.625)^2 + (1.875-1.875)^2 = 0.5.

So the best first stump is

\hat h_1(x)= \begin{cases} -0.625, & x \leq 3.5, \\ 1.875, & x > 3.5. \end{cases}

Part 3: Shrinkage update

With \nu=0.4,

\hat F_1(x)=\hat F_0(x)+0.4\,\hat h_1(x).

Therefore

\hat F_1(x)= \begin{cases} 3.125 + 0.4(-0.625)=2.875, & x \leq 3.5, \\ 3.125 + 0.4(1.875)=3.875, & x > 3.5. \end{cases}

So the fitted values at the four training points are

(2.875,\ 2.875,\ 2.875,\ 3.875).

Part 4: The effect of shrinkage on the training fit

After the update, the new residuals are r_{t+1}-\nu\hat h_1(x_t), so

\mathrm{SSE}(\nu) =\sum_t\bigl(r_{t+1}-\nu\hat h_1(x_t)\bigr)^2 =\sum_t r_{t+1}^2-2\nu\sum_t r_{t+1}\hat h_1(x_t)+\nu^2\sum_t\hat h_1(x_t)^2.

Within each leaf, \hat h_1 is constant and equals the mean of the residuals in that leaf. Summing leaf by leaf therefore gives

\sum_t r_{t+1}\hat h_1(x_t) =\sum_{\text{leaves}}\hat h_{\text{leaf}}\sum_{t\in\text{leaf}}r_{t+1} =\sum_{\text{leaves}} n_{\text{leaf}}\,\hat h_{\text{leaf}}^2 =\sum_t\hat h_1(x_t)^2,

and substituting this identity into the expansion yields

\mathrm{SSE}(\nu)=\sum_t r_{t+1}^2-\nu(2-\nu)\sum_t\hat h_1(x_t)^2.

Numerically, \sum_t r_{t+1}^2=1.125^2+0.125^2+0.625^2+1.875^2=5.1875 and \sum_t\hat h_1(x_t)^2=3\times 0.625^2+1.875^2=4.6875. At \nu=0.4 the formula gives 5.1875-0.4\times 1.6\times 4.6875=2.1875, which matches the direct computation using the fitted values from Part 3:

(2-2.875)^2 + (3-2.875)^2 + (2.5-2.875)^2 + (5-3.875)^2 = 2.1875.

At \nu=1 the formula gives 5.1875-4.6875=0.5, again matching the direct computation with fitted values (2.5,\,2.5,\,2.5,\,5):

(2-2.5)^2 + (3-2.5)^2 + (2.5-2.5)^2 + (5-5)^2 = 0.5.

Because \nu(2-\nu) is strictly increasing on (0,1], the training SSE after one update is strictly decreasing in \nu: the full step always fits the training sample at least as well as any shrunken step. Out of sample this is beside the point. Boosting is a multi-step procedure, the learning rate regularizes the whole path of updates, and the combination of \nu and the stopping iteration M is chosen on validation data; cautious updates often generalize better than aggressive early corrections even though they lose the one-step training comparison by construction.

Part 5: Selecting the iteration count for a time series

Random K-fold validation mixes earlier and later months. A training fold can therefore contain outcomes that were unavailable at the validation forecast origin. This design does not reproduce historical training information sets. That mismatch need not bias a risk estimate under every stationary data-generating process, but random folds require additional justification; calendar ordering alone provides none, as discussed in the cross-validation chapter.

If later observations reveal a regime-specific relationship that is useful for a validation month, a larger-M ensemble may exploit that relationship more fully than a smaller one. Random folds can then favor an overly long boosting path relative to a real-time design. Under structural change, later observations can instead describe a relationship inappropriate for an earlier validation month, so neither the sign of the risk distortion nor the direction of the change in selected M is guaranteed.

Choose M using rolling or expanding windows. At each validation origin t, estimate preprocessing and the boosting path using only predictor–outcome pairs whose required values are available by t, then score predictions of y_{t+1} using x_t. Minimize average loss across those ordered origins. Because that average has been used to choose M, assess the selected procedure on a later untouched test period. If deployment retunes M over time, an outer sequence of forecast origins must repeat the entire tuning procedure using only information available at each outer origin.

Part 6: An interaction that stumps cannot represent

Every stump is a function of at most one predictor. Grouping the terms in \hat F_M=\hat F_0+\nu\sum_{m=1}^M\hat h_m by their split variable therefore gives

\hat F_M(x_1,x_2)=a+g_1(x_1)+g_2(x_2),

where a includes the initial constant and any constant trees, and g_1,g_2 collect the scaled stumps on the two indicators. For every such fit,

\begin{aligned} &F(1,1)-F(1,0)-F(0,1)+F(0,0)\\ &=[a+g_1(1)+g_2(1)]-[a+g_1(1)+g_2(0)]\\ &\quad-[a+g_1(0)+g_2(1)]+[a+g_1(0)+g_2(0)] =0. \end{aligned}

For f(x_1,x_2)=x_1x_2, the same contrast is 1-0-0+0=1. Thus no stump ensemble can match all four conditional means, regardless of the number of iterations or the learning rate. More iterations cannot remove this restriction on interactions.

A depth-2 tree can represent f: split first at x_1=0.5 and assign the left leaf the value 0. In the right branch, split at x_2=0.5, assigning values 0 and 1 to its left and right leaves. The tree predicts 1 exactly when both indicators equal one.

Exercise 12.2: Bernoulli Boosting, Initialization, and Newton Leaf Updates

Consider binary outcomes y_i\in\{0,1\} and a boosting model with finite log-odds F(x_i) and probability

p_i=\sigma(F(x_i))=\frac{1}{1+e^{-F(x_i)}}.

The per-observation Bernoulli log-loss is

\ell(y_i,z)=-y_i\log\sigma(z)-(1-y_i)\log(1-\sigma(z)).

  1. Derive the first and second derivatives of \ell(y_i,z) with respect to z, and hence the pseudo-residual at the current fit. For a sample containing both classes, use these derivatives to find the loss-minimizing constant initial model \hat F_0(x)\equiv c and prove that the minimizer is unique.
  2. What happens to the constant-model minimization when \bar y=0 or \bar y=1? To obtain a finite convention, constrain the initial probability to p\in[\varepsilon,1-\varepsilon], where 0<\varepsilon<1/2. Derive the constrained optimum for any \bar y\in[0,1]. When \bar y=0, compute the sum of the resulting pseudo-residuals and explain why it need not be zero at this constrained optimum.
  3. Fix a nonempty leaf R and hold its current log-odds F(x_i) fixed. Define the loss from a common leaf correction \gamma as Q(\gamma)=\sum_{i:\,x_i\in R}\ell(y_i,F(x_i)+\gamma). Derive Q'(0) and Q''(0), and minimize the second-order Taylor approximation to Q around \gamma=0 to obtain the one-step Newton correction \widetilde\gamma. Explain why the bound on individual pseudo-residuals does not bound |\widetilde\gamma| uniformly.
  4. A leaf contains two observations with outcomes (1,0) and the same current probability p. Compute \widetilde\gamma at p=0.6 and at p=0.9. Derive the exact loss-minimizing correction \gamma^\star in each case, and explain the difference between the Newton corrections in terms of the summed residual and total curvature. Exact logarithms are acceptable.
  5. For the p=0.9 case, let F=\log 9 denote the common current log-odds and write the leaf loss at common log-odds z as q(z)=\log(1+e^{-z})+\log(1+e^z). Show that q is even and strictly increasing for z>0. Use this property to determine whether the full Newton step lowers the leaf loss. Then find all learning rates \nu\in(0,1] for which q(F+\nu\widetilde\gamma)<q(F), and check whether \nu=0.4 satisfies the condition. You may use \log9\approx2.1972.

Exam level: suitable as-is. Parts 1–2 study initialization and boundary constraints, Part 3 derives the Newton leaf correction, and Parts 4–5 compare that correction with exact loss minimization and diagnose when shrinkage prevents a loss increase.

Hint for Part 2

Differentiate the constant-model loss with respect to the probability p. Its derivative changes sign at \bar y when that point is inside the allowed interval. At an endpoint, a constrained minimum need not satisfy the unrestricted first-order condition.

Hint for Part 3

The quadratic approximation is Q(0)+Q'(0)\gamma+\tfrac12Q''(0)\gamma^2. The derivatives are evaluated at the probabilities before the update. To test whether the correction can be large, consider a leaf with both outcomes present but all current probabilities approaching one.

Hint for Part 5

Evenness and monotonicity make the loss comparison equivalent to comparing |F+\nu\widetilde\gamma| with F>0. Solve the resulting double inequality for \nu.

Solution

Part 1: Derivatives and the unique constant initialization

Writing p=\sigma(z) and using dp/dz=p(1-p) gives

\begin{aligned} \frac{\partial\ell(y_i,z)}{\partial z} &=-y_i(1-p)+(1-y_i)p=p-y_i,\\ \frac{\partial^2\ell(y_i,z)}{\partial z^2}&=p(1-p)>0. \end{aligned}

Thus the pseudo-residual at z=F(x_i) is r_i=y_i-p_i. For the constant model, every probability equals p=\sigma(c), and

L'(c)=\sum_{i=1}^N(p-y_i)=N(p-\bar y), \qquad L''(c)=Np(1-p)>0.

When 0<\bar y<1, the first-order condition has the finite solution

\hat F_0(x)\equiv c=\log\left(\frac{\bar y}{1-\bar y}\right).

Strict convexity makes this stationary point the unique global minimizer.

Part 2: Boundary samples and a finite constraint

If \bar y=1, then L(c)=-N\log\sigma(c) is strictly decreasing and approaches its infimum of zero only as c\to+\infty. If \bar y=0, the loss is strictly increasing in c and approaches zero only as c\to-\infty. Neither sample has a finite unconstrained minimizer.

For the constrained problem, write the loss directly as a function of p:

L(p)=-N\left[\bar y\log p+(1-\bar y)\log(1-p)\right], \qquad \frac{dL(p)}{dp}=\frac{N(p-\bar y)}{p(1-p)}.

The denominator is positive throughout [\varepsilon,1-\varepsilon]. The loss decreases for p<\bar y and increases for p>\bar y, so its constrained minimizer is

\hat p=\min\{1-\varepsilon,\max\{\varepsilon,\bar y\}\}, \qquad \hat c=\log\left(\frac{\hat p}{1-\hat p}\right).

When \bar y=0, every residual is -\varepsilon, giving

\sum_{i=1}^N r_i=-N\varepsilon.

The nonzero sum is consistent with constrained optimality. The unrestricted loss would decrease if p moved below \varepsilon, but that direction is infeasible. Clipping yields a finite constrained solution; it does not produce a finite stationary point of the original unconstrained loss.

Part 3: Deriving the Newton correction

The current probabilities p_i=\sigma(F(x_i)) give

Q'(0)=\sum_{i:\,x_i\in R}(p_i-y_i), \qquad Q''(0)=\sum_{i:\,x_i\in R}p_i(1-p_i).

The curvature is positive because the leaf is nonempty and every current log-odds value is finite. Differentiating the quadratic approximation with respect to \gamma gives Q'(0)+Q''(0)\gamma. Its unique minimizer is therefore

\widetilde\gamma =-\frac{Q'(0)}{Q''(0)} =\frac{\sum_{i:\,x_i\in R}(y_i-p_i)} {\sum_{i:\,x_i\in R}p_i(1-p_i)}.

Positive curvature need not be bounded away from zero. For example, in a two-observation leaf with outcomes (1,0) and a common probability p\to1, the numerator 1-2p approaches -1 while the denominator 2p(1-p) approaches zero. Thus \widetilde\gamma\to-\infty although both pseudo-residuals remain between -1 and 1.

Part 4: Newton steps and exact leaf minimizers

With one outcome of each class and a common current probability p,

\widetilde\gamma=\frac{1-2p}{2p(1-p)}.

The two numerical cases give

\begin{aligned} p=0.6:\quad \widetilde\gamma&=\frac{-0.2}{0.48} =-\frac{5}{12}\approx-0.4167,\\ p=0.9:\quad \widetilde\gamma&=\frac{-0.8}{0.18} =-\frac{40}{9}\approx-4.4444. \end{aligned}

The current log-odds are F=\log[p/(1-p)]. The exact leaf derivative is Q'(\gamma)=2\sigma(F+\gamma)-1, so the unique minimizer satisfies F+\gamma^\star=0. Consequently,

\begin{aligned} p=0.6:\quad \gamma^\star&=-\log(3/2)\approx-0.4055,\\ p=0.9:\quad \gamma^\star&=-\log9\approx-2.1972. \end{aligned}

Moving p from 0.6 to 0.9 quadruples the magnitude of the summed residual, from 0.2 to 0.8, and reduces total curvature from 0.48 to 0.18. Both changes increase the magnitude of the Newton correction. The first correction is close to the exact minimizer; the second passes well beyond it. Overshooting the minimizer alone does not establish that loss increases, so Part 5 compares the attained losses.

Part 5: When shrinkage prevents a loss increase

Replacing z by -z interchanges the two terms of q(z), so q(-z)=q(z). Also,

q'(z)=2\sigma(z)-1>0 \qquad\text{for }z>0.

Thus loss is strictly increasing in |z|. With F=\log9\approx2.1972 and \widetilde\gamma=-40/9, the full step produces

F+\widetilde\gamma =\log9-\frac{40}{9}\approx-2.2472.

Its absolute value exceeds the starting value F, so q(F+\widetilde\gamma)>q(F). The full Newton step increases the leaf loss despite starting in a descent direction.

A shrunken step lowers loss exactly when

\begin{aligned} \left|F-\frac{40}{9}\nu\right|<F &\quad\Longleftrightarrow\quad -F<F-\frac{40}{9}\nu<F\\ &\quad\Longleftrightarrow\quad 0<\nu<\frac{9\log9}{20}\approx0.9888. \end{aligned}

The upper bound lies below one, so this is the full interval within the allowed range \nu\in(0,1]. At the upper endpoint the loss equals its starting value; at \nu=1 it is higher. The learning rate \nu=0.4 lies inside the interval and therefore reduces the leaf loss. This bound is specific to the stated leaf and current probabilities: shrinkage can prevent this overshoot without making every fixed learning rate safe for every Newton update.
