6 Recurrent Neural Networks

6.1 Overview

Feed-forward neural networks (FNNs) are flexible nonlinear maps from an input vector to an output, but they do not have a built-in state variable. If we want to use them for time-series forecasting, we usually have to create lagged inputs manually, such as the L most recent observations (y_t, y_{t-1}, \ldots, y_{t-L+1}). That approach is often useful, but it fixes the memory length L in advance and treats temporal dependence as a feature-engineering problem.

Recurrent neural networks (RNNs) instead maintain a hidden state that is updated as new observations arrive. This makes them closer in spirit to econometric models with recursively updated states. Examples include autoregressive moving-average (ARMA) models, generalized autoregressive conditional heteroskedasticity (GARCH) models, and state-space models, which represent dynamics through a state that is updated or filtered over time. Both classical recursions and RNNs estimate coefficients within a chosen function family. ARMA and GARCH models use parsimonious recursions for quantities such as conditional means and variances; an RNN uses a neural-network update to learn predictive features of the history. Its architecture, including the dimension of the state, the connections, and the activation function, still restricts the admissible update functions. Estimation selects the weights and biases within that family.

This chapter introduces the basic RNN architecture in a forecasting setting, interprets it through an econometric state-variable lens, explains how training works when the data are one long time series, and then turns to the central difficulty of RNNs: vanishing and exploding gradients. The basic recurrent architecture is closely associated with Elman (1990), while training through an unrolled sequence uses the backpropagation ideas of Rumelhart, Hinton, and Williams (1986) and backpropagation through time as described by Werbos (1990). The vanishing-gradient difficulty is analyzed in Bengio, Simard, and Frasconi (1994). That difficulty is the main reason why the next chapter moves to Long Short-Term Memory (LSTM) networks.

6.2 Roadmap

  1. We first define the forecasting setup and ask how a model can use the available history.
  2. We contrast a lagged feed-forward network with a recurrent state update.
  3. We introduce the RNN equations, parameter sharing—the same weights reused at every date—and the unrolled computational graph, in which the recurrence is drawn out over time as a chain.
  4. We connect RNNs to econometric state-variable models such as GARCH.
  5. We discuss deterministic versus probabilistic outputs for forecasting applications.
  6. We derive backpropagation through time and analyze the vanishing and exploding gradient problems.
  7. We finish with training practice—how one long series becomes many training windows, why the backward gradient computation is cut off after a fixed number of steps, and why using the same parameters at every date amounts to assuming stable dynamics—and with the motivation for LSTMs.

6.3 Forecasting Setup and the Information Set

Suppose we want to forecast a scalar outcome Y_{t+1} using information available at time t. Recall the forecast-origin information set \mathcal{F}_t from the time-series cross-validation discussion: it contains the variables in the form in which they were actually available at the forecast origin. In a macroeconomic or financial application, \mathcal{F}_t may contain past values of the target variable, lagged predictors, realized returns, volatility measures, survey variables, text-based indicators, and other signals known at time t.

A lagged feed-forward network uses a fixed window of this information. Write f_\theta for its prediction map, where \theta collects that network’s trainable weights and biases. For example,

\hat{y}_{t+1\mid t} = f_\theta(y_t, y_{t-1}, \ldots, y_{t-L+1}, \mathbf{x}_t, \mathbf{x}_{t-1}, \ldots, \mathbf{x}_{t-L+1}).

Here \hat{y}_{t+1\mid t} denotes a forecast of Y_{t+1} formed at the origin t; the two-index subscript records both dates, and the forecast itself is built from the realized history, following the book’s case convention. This is a reasonable baseline. It is close to how econometricians build distributed-lag or autoregressive forecasting models. The limitation is that the window length L must be chosen before estimation, and the model does not update an internal state as new observations arrive.

From this point onward, \mathbf{x}_t denotes the complete per-period input to the RNN. It may include y_t together with any other predictors known at time t. An RNN computes a hidden state \mathbf{h}_t by processing the inputs (\mathbf{x}_1, \ldots, \mathbf{x}_t) in order from a fixed initial state. The hidden state replaces the fixed lag vector with a recursively updated summary.

The hidden state \mathbf{h}_t is neither an observed economic variable nor a latent stochastic state that must be filtered. Once the network parameters and initial state are fixed, \mathbf{h}_t is computed exactly from the input history. It is a learned vector summary of the past that is useful for prediction.

Econometric Interpretation

An RNN carries information forward through a state variable, as a state-space model or a GARCH recursion does. Its state coordinates are learned predictive features rather than quantities assigned a specific econometric meaning. The neural architecture specifies the family of state-update functions, and estimation fits its weights and biases.

6.4 From a Lagged FNN to a Recurrent State

The previous section described the hidden state abstractly, as a recursively updated summary of the past. We now make the recursion explicit. A feed-forward network with lagged inputs can learn nonlinear relationships among all the lags supplied to it, but cannot access additional history unless that history is summarized in an included feature. An RNN instead processes inputs sequentially, compressing them into a hidden state with the same update rule at every step. If the state is carried forward without resets, all earlier inputs can in principle influence the current prediction through that state. The fixed-window training scheme introduced later truncates this history in estimation.

Write g_\theta for the RNN’s state-update map and q_\theta for its output map. Here \theta collects the RNN’s trainable weights and biases, a separate parameter collection from that of the lagged FNN. At time t, the state-update map combines the current input \mathbf{x}_t and the previous hidden state \mathbf{h}_{t-1} to produce the new hidden state:

\mathbf{h}_t = g_\theta(\mathbf{h}_{t-1}, \mathbf{x}_t).

The output map q_\theta then turns the state into a forecast, classification probability, or distributional parameter. For a scalar output,

\hat{y}_{t+1\mid t} = q_\theta(\mathbf{h}_t).

The essential point is that the model learns both the update rule and the predictive mapping.

6.5 RNN Architecture and Notation

The recurrence can be visualized in two ways: a compact form with a self-loop, representing the recurrence, and an “unrolled” form, which shows the flow of information through time.

The left panel in Figure 6.1 shows the compact representation: a recurrent link feeds the previous hidden state into the next state update. The right panel draws three consecutive updates from a longer sequence, with the ellipses showing that the recurrence continues on both sides. Unrolling is mainly a computational device for training; the same update rule and parameters are reused at every date.

The output carries the two-index subscript introduced above: \hat{\mathbf{y}}_{t+1\mid t} is formed at origin t and concerns date t+1. In a scalar one-step-ahead application it is the point forecast \hat{y}_{t+1\mid t}; more generally it collects the parameters of the predictive distribution of Y_{t+1} given \mathcal{F}_t. As everywhere in the book, an unhatted lowercase y_s denotes the outcome realized at calendar time s, and uppercase Y_s the corresponding random variable.

At each time step t, define:

  • \mathbf{x}_t \in \mathbb{R}^{p}: The input vector at the current time step (e.g., today’s stock returns and trading volume); p is the per-period input dimension, as in the feed-forward chapter.
  • \mathbf{h}_{t-1} \in \mathbb{R}^{H}: The hidden state from the previous time step, which acts as the network’s memory of the past.
  • \mathbf{h}_t \in \mathbb{R}^{H}: The new hidden state, calculated by combining the current input \mathbf{x}_t with the previous state \mathbf{h}_{t-1}.
  • \hat{\mathbf{y}}_{t+1\mid t} \in \mathbb{R}^{O}: The output produced at forecast origin t for date t+1 (e.g., the prediction for the next period’s volatility), obtained from the current hidden state. The hat marks it as a model output rather than an observed quantity.

For the basic RNN, the maps g_\theta and q_\theta take the following concrete forms. Write g for the fixed hidden-state activation, applied componentwise, and g_{\mathrm{out}} for the output activation, chosen to match the forecasting object:

\begin{aligned} \mathbf{h}_t &= g_\theta(\mathbf{h}_{t-1}, \mathbf{x}_t) \\ &= g(\mathbf{W}_{hh}\mathbf{h}_{t-1} + \mathbf{W}_{xh}\mathbf{x}_t + \mathbf{b}_h), \\[0.5em] \hat{\mathbf{y}}_{t+1\mid t} &= q_\theta(\mathbf{h}_t) \\ &= g_{\mathrm{out}}(\mathbf{W}_{hy}\mathbf{h}_t + \mathbf{b}_y). \end{aligned}

The activation g is one component of the full state-update map g_\theta; it does not include the weights and biases. The output activation may be the identity for an unrestricted point forecast, a sigmoid for a binary-event probability, softmax for probabilities over several classes, or softplus for a positive variance forecast. These choices are the output activations introduced in the feed-forward networks chapter.

We fix \mathbf{h}_0 by convention, typically \mathbf{h}_0 = \mathbf{0}, since the state recursion is otherwise undefined at t=1. The trainable parameters are:

  • \mathbf{W}_{hh} \in \mathbb{R}^{H \times H} (hidden-to-hidden weights)
  • \mathbf{W}_{xh} \in \mathbb{R}^{H \times p} (input-to-hidden weights)
  • \mathbf{W}_{hy} \in \mathbb{R}^{O \times H} (hidden-to-output weights)
  • \mathbf{b}_h \in \mathbb{R}^{H}, \mathbf{b}_y \in \mathbb{R}^{O} (bias terms)

The letter pairs in the matrix names give the source then the destination: xh means input-to-hidden and hy means hidden-to-output. Matrix entries retain the convention from the feed-forward chapter: rows index receiving units and columns index sending units.

The RNN’s parameter collection is \theta = \{\mathbf{W}_{hh}, \mathbf{W}_{xh}, \mathbf{W}_{hy}, \mathbf{b}_h, \mathbf{b}_y\}. The state-update map g_\theta uses the first two matrices and \mathbf{b}_h; the output map q_\theta uses \mathbf{W}_{hy} and \mathbf{b}_y.

Optional direct input-to-output connection. A further weight matrix \mathbf W_{xy}\in\mathbb R^{O\times p} lets the current input affect the output directly. The output map then takes both the hidden state and the current input as arguments:

\begin{aligned} \hat{\mathbf y}_{t+1\mid t} &=q_\theta(\mathbf h_t,\mathbf x_t) \\ &=g_{\mathrm{out}}(\mathbf W_{hy}\mathbf h_t+\mathbf W_{xy}\mathbf x_t+\mathbf b_y). \end{aligned}

The additional matrix joins the trainable parameter collection \theta. The hidden state still provides the recurrent summary of the past. Setting \mathbf W_{xy}=\mathbf0 recovers the basic architecture used in this chapter’s figures and exercises.

Why use tanh? We use \tanh as the hidden-state activation g, recalling its shape from the activation-function discussion. Its range (-1,1) keeps every hidden-state component bounded through repeated updates. Its symmetry around zero lets a unit represent both positive and negative values. Near zero, \tanh(z)\approx z and \tanh'(0)=1, so the activation approximately preserves small changes in its argument while allowing nonlinear responses away from zero (Goodfellow, Bengio, and Courville 2016, sec. 6.3.2).

The tradeoff is saturation: for large absolute arguments, tanh flattens near \pm1, and its derivative \tanh'(z)=1-\tanh^2(z) approaches zero. Repeated multiplication by small derivatives can weaken the learning signal from distant inputs. Bounded hidden-state values do not guarantee bounded gradients, either: gradient propagation also involves \mathbf W_{hh}. We derive both effects in Section 6.9.

Before listing the properties of this recursion, we follow it through two dates with numbers.

Example: Two recurrent updates

Consider a single hidden unit with a scalar input and an identity output activation, g_{\mathrm{out}}(z)=z, so that every quantity is a scalar and we drop the boldface. The supplied parameters are W_{xh}=1, W_{hh}=0.5, b_h=0, W_{hy}=1.2, and b_y=0; the initial state is h_0=0; the inputs are x_1=0.4 and x_2=0.2. Use \tanh(0.4)\approx 0.380 and \tanh(0.39)\approx 0.371. The two updates are

\begin{aligned} h_1 &= \tanh(W_{hh}h_0 + W_{xh}x_1 + b_h) \\ &= \tanh(0.5\times 0 + 0.4) \approx 0.380, \\[0.5em] h_2 &= \tanh(W_{hh}h_1 + W_{xh}x_2 + b_h) \\ &= \tanh(0.5\times 0.380 + 0.2) \\ &= \tanh(0.39) \approx 0.371, \end{aligned}

and the output at origin 2 is \hat{y}_{3\mid 2} = W_{hy}h_2 + b_y \approx 0.445, the forecast of Y_3. The same three weights and two biases are used at both dates; only the input and the previous state change. The first input x_1 affects h_2, and hence \hat{y}_{3\mid 2}, only through h_1; the training section differentiates exactly this route.

Key Properties

  • Parameter sharing: The same weight matrices (\mathbf{W}_{hh}, \mathbf{W}_{xh}, \mathbf{W}_{hy}) and biases are used at every time step. The total parameter count is therefore independent of sequence length, so the same network can be applied to sequences of different lengths.
  • Memory: The hidden state \mathbf{h}_t carries information from past inputs forward, so observations at t-d for d\geq 1 can still influence \hat{y}_{t+1\mid t} through the state.

6.6 Econometric State-Variable Interpretation

An RNN models time-series dynamics through a recursively updated state. A useful econometric benchmark is the GARCH model of Bollerslev (1986).

In the GARCH(1,1) model, the return at t is decomposed as R_t = \mu_t + \varepsilon_t, where \mu_t=\mathbb{E}[R_t\mid\mathcal{F}_{t-1}] and \varepsilon_t=\sigma_t Z_t. The innovations Z_t are independent and identically distributed, independent of \mathcal{F}_{t-1}, and normalized so that \mathbb{E}[Z_t]=0 and \mathbb{E}[Z_t^2]=1. Under these conditions, \sigma_t^2=\operatorname{Var}(\varepsilon_t\mid\mathcal{F}_{t-1}). GARCH indexes the variance by the date of the innovation whose variance it describes. At forecast origin t, its next-period update is

\sigma_{t+1}^2 = \omega + \alpha \varepsilon_t^2 + \beta \sigma_t^2,

where \omega>0 and \alpha,\beta\geq 0. Under the stated normalization, covariance stationarity with finite unconditional innovation variance requires \alpha+\beta<1; that variance is \omega/(1-\alpha-\beta). The update combines the previous variance state \sigma_t^2 with the newly observed squared innovation \varepsilon_t^2 to produce \sigma_{t+1}^2.

An RNN-style volatility model could instead use

\begin{aligned} \mathbf{h}_t &= \tanh(\mathbf{W}_{hh}\mathbf{h}_{t-1} + \mathbf{W}_{xh}\mathbf{x}_t + \mathbf{b}_h) \\ \sigma_{t+1}^2 &= \text{softplus}(\mathbf{W}_{hy}\mathbf{h}_t + \mathbf{b}_y), \end{aligned}

where \mathbf{x}_t might contain lagged returns, squared returns, realized volatility measures, or macro-financial predictors known at time t. Both models use information available at t to forecast the variance at t+1. In the RNN, the hidden state \mathbf{h}_t learns a vector summary of the history, and the separate output map turns that summary into a positive variance forecast.

The analogy has clear limits. A GARCH conditional variance is an observation-driven state (Cox 1981): given the parameters, mean specification, and initial variance, it is computed recursively from past observations. Its probabilistic role is the conditional variance of the innovation; specifying the distribution of Z_t additionally gives a full conditional distribution. An RNN hidden state is likewise observation-driven, a deterministic function of past inputs given its parameters and initialization, but its components carry no assigned probabilistic role: the hidden state is a predictive representation. The RNN becomes a probabilistic econometric model once we specify how its output maps into a conditional distribution. A proper scoring rule then determines how the parameters of that model are estimated.

RNNs and Classical Time-Series Models

The hidden state \mathbf{h}_t plays a role similar to a state vector in a state-space model or a volatility state in GARCH. Like the GARCH variance, \mathbf{h}_t is exactly computable from past inputs once the model parameters and initial state are fixed. A latent state in a stochastic state-space model instead requires filtering: inference about its conditional distribution given the observations. The RNN’s state coordinates are learned predictive features, without a direct one-to-one econometric interpretation.

6.7 Outputs and Loss Functions

The output layer determines what kind of forecasting object the RNN produces. For a conditional mean forecast, we can use a linear output

\hat{y}_{t+1\mid t} = \mathbf{W}_{hy}\mathbf{h}_t + \mathbf{b}_y

and train by minimizing squared loss. For a binary event, such as recession prediction, we can pass the output through a sigmoid and train with cross-entropy. For a probabilistic forecast, the output should parameterize a distribution and be trained with a proper scoring rule. For example, suppose we impose a zero conditional mean for returns, \mu_{t+1}=0. A Gaussian RNN model then specifies

\begin{aligned} R_{t+1} \mid \mathcal{F}_t &\sim \mathcal{N}(0, \sigma_{t+1}^2), \\ \sigma_{t+1}^2 &= \text{softplus}(\mathbf{W}_{hy}\mathbf{h}_t + \mathbf{b}_y). \end{aligned}

The training score is evaluated on the realized returns r_{t+1}. The zero-mean restriction is a modeling choice; a nonzero mean can instead be estimated jointly with the variance using an additional unrestricted output, as developed in the distributional networks chapter.

A deterministic RNN trained by squared loss gives a point forecast. A distributional RNN gives a predictive distribution; negative log-likelihood is one familiar training score, but other differentiable proper scores, such as the continuous ranked probability score (CRPS), are also valid. The resulting forecasts can be evaluated with the scoring rules from the predictive-distribution chapter.

From next-token prediction to foundation models

Text is another ordered sequence. Consider continuing a central-bank statement beginning “Inflation is expected to”. We first divide the text into tokens: units such as words, word fragments, or punctuation. The prediction steps now correspond to positions in the text. An RNN takes a numerical encoding of each token as input and updates its hidden state using the same recurrence as above. A softmax output assigns probabilities to the possible next tokens in its vocabulary, the set of tokens it can predict. Training uses the observed preceding tokens and minimizes cross-entropy: the negative log probability assigned to the actual next token, summed or averaged across positions. Recurrent language models use precisely this forecasting setup (Mikolov et al. 2010).

To generate text, first process a prompt, the supplied starting text. Then sample a next token from the output distribution, feed that token into the RNN, and repeat. With the fitted weights held fixed, the hidden state changes as the generated sequence grows. This is autoregressive generation: each new token is predicted conditional on the preceding tokens.

A foundation model is trained on broad data at scale and can be adapted to many subsequent tasks (Bommasani et al. 2021). Next-token prediction can provide this initial training, called pretraining, as in Brown et al. (2020). The architecture need not be recurrent. A Transformer uses attention to combine numerical vectors representing tokens, with weights that depend on the text (Vaswani et al. 2017). For next-token prediction, it can access only positions before the token being predicted, within a limited span called the context window. An RNN carries the preceding text through its recurrent hidden state; a Transformer can access vectors at multiple positions within that window. The forecasting objective can therefore be the same even though the mechanism for using the past differs.

Forecast-Origin Discipline

For time-series applications, \mathbf{x}_t and \mathbf{h}_t must only use information available at the forecast origin. The recurrent architecture does not remove the usual econometric concern about look-ahead bias, revised macroeconomic data, publication lags, or temporal leakage in validation.

Question for Reflection

If a macroeconomic predictor is published with a one-month delay and later revised, what should be included in \mathcal{F}_t when training an RNN for real-time forecasting?

Suggested Answer

\mathcal{F}_t should contain only the data vintage available at forecast origin t. With a one-month publication delay, the current-month value is not yet available, and revisions released after t are also unavailable. Each training row should therefore use the vintage that had been released by its own forecast origin, rather than values from the revised historical series available later.

6.8 Training Through Time

Training an RNN raises a problem absent from feed-forward networks: because the same weight matrices (\mathbf{W}_{hh}, \mathbf{W}_{xh}) are applied at every time step, the gradient with respect to each matrix is the sum of contributions from every time step. The algorithm that handles this is backpropagation through time (BPTT).

The core idea of BPTT is to unroll the network through time, as shown in Figure 6.1. This conceptually transforms the RNN into a deep feed-forward network where each time step becomes a layer, but with the critical constraint that the weights are shared across all layers. Once unrolled, standard backpropagation can be applied.

For clarity, the chapter specializes to a single terminal loss evaluated at the terminal step T, written in the forecasting convention: the step-T output is scored against the outcome it forecasts,

L_T = \ell(y_{T+1}, \hat{\mathbf{y}}_{T+1\mid T}),

with the observed target first and the network output second, as in the feed-forward networks chapter. For an objective with a loss at every step, the gradient is obtained by summing analogous contributions over the per-step losses \sum_{t=1}^{T}\ell(y_{t+1},\hat{\mathbf{y}}_{t+1\mid t}).

Notation: Gradients and Jacobians

All vectors are columns. We use the conventions from feed-forward backpropagation, with i and j indexing hidden units (matrix rows and columns):

  • The loss gradient \nabla_{\mathbf{h}_t}L_T is an H\times1 column vector; its i-th entry is \partial L_T/\partial(\mathbf{h}_t)_i.
  • The loss gradient \nabla_{\mathbf{W}_{hh}}L_T is an H\times H matrix; its (i,j)-th entry is \partial L_T/\partial(\mathbf{W}_{hh})_{ij}. A matrix gradient has the same shape as the parameter matrix it updates.
  • The vector derivative \partial\mathbf{h}_t/\partial\mathbf{h}_s is an H\times H Jacobian; its (i,j)-th entry is \partial(\mathbf{h}_t)_i/\partial(\mathbf{h}_s)_j. Rows index the resulting state, and columns index the state being perturbed.

We use \nabla for scalar-loss gradients with respect to vectors or matrices, and \partial for ordinary scalar derivatives and vector-to-vector Jacobians. The chain rule propagates column gradients backward by multiplying by the transpose of the forward Jacobian.

From one weight to a matrix gradient. Define the pre-activation \mathbf{z}_t=\mathbf{W}_{hh}\mathbf{h}_{t-1}+\mathbf{W}_{xh}\mathbf{x}_t+\mathbf{b}_h. As in feed-forward backpropagation, let \boldsymbol{\delta}_t be the gradient of the terminal loss with respect to this pre-activation:

\begin{aligned} \boldsymbol{\delta}_t &= \nabla_{\mathbf{z}_t}L_T \\ &= \operatorname{diag}\big(g'(\mathbf{z}_t)\big) \nabla_{\mathbf{h}_t}L_T. \end{aligned}

The vector g'(\mathbf{z}_t) contains the componentwise activation derivatives, and \operatorname{diag} places them on the diagonal of an H\times H matrix. Thus \boldsymbol{\delta}_t is an H\times1 column vector that includes all downstream effects on L_T.

For a single recurrent weight (\mathbf{W}_{hh})_{ij}, its direct effect on (\mathbf{z}_t)_i at step t is (\mathbf{h}_{t-1})_j, holding the previous state fixed. Summing the contributions from its repeated use gives

\frac{\partial L_T}{\partial(\mathbf{W}_{hh})_{ij}} = \sum_{t=1}^{T}(\boldsymbol{\delta}_t)_i(\mathbf{h}_{t-1})_j.

Stacking these scalar derivatives yields the matrix gradient

\nabla_{\mathbf{W}_{hh}}L_T = \sum_{t=1}^{T}\boldsymbol{\delta}_t\mathbf{h}_{t-1}^{\top}.

Each summand is an outer product: an H\times1 column times a 1\times H row, giving an H\times H matrix. The previous state is held fixed only when differentiating the local step-t update; its own dependence on the shared weights enters through the other time-step contributions. Including that dependence again in the local factor would double-count paths. This componentwise construction avoids treating \partial\mathbf{h}_t/\partial\mathbf{W}_{hh}, which would have three coordinate indices, as an ordinary matrix.

Propagating the state gradient backward. The column gradient \nabla_{\mathbf{h}_t}L_T measures how an adjustment to the hidden state at time t affects the terminal loss. The chain rule gives

\nabla_{\mathbf{h}_t}L_T = \left(\frac{\partial\mathbf{h}_T}{\partial\mathbf{h}_t}\right)^{\top} \nabla_{\mathbf{h}_T}L_T.

The dimensions are (H\times H)(H\times1)=H\times1. At the terminal step, \nabla_{\mathbf{h}_T}L_T differentiates through the output map q_\theta, including its output activation g_{\mathrm{out}}; an identity output activation is not required.

For an earlier date s<t, the forward state Jacobian is the ordered product

\begin{aligned} \frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_s} &= \frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_{t-1}}\, \frac{\partial \mathbf{h}_{t-1}}{\partial \mathbf{h}_{t-2}}\cdots \frac{\partial \mathbf{h}_{s+1}}{\partial \mathbf{h}_{s}}, \\[0.5em] \frac{\partial \mathbf{h}_k}{\partial \mathbf{h}_{k-1}} &= \operatorname{diag}\big(g'(\mathbf{z}_k)\big)\,\mathbf{W}_{hh}, \end{aligned}

where k indexes time and each factor is H\times H. Each one-step Jacobian follows from \mathbf{h}_k = g(\mathbf{z}_k) with \mathbf{z}_k affine in \mathbf{h}_{k-1}. The factors need not commute, so their order matters. For backward propagation, the one-step transpose is \mathbf{W}_{hh}^{\top}\operatorname{diag}(g'(\mathbf{z}_k)): transposing reverses the multiplication order.

The backward calculation can therefore be implemented one step at a time. Starting from \nabla_{\mathbf h_T}L_T, compute \boldsymbol\delta_t as above, accumulate the weight-gradient contribution, and propagate to the previous state using

\nabla_{\mathbf h_{t-1}}L_T = \mathbf W_{hh}^{\top}\boldsymbol\delta_t, \qquad t=T,T-1,\ldots,1.

When H=1, gradients and Jacobians reduce to scalar derivatives and the transposes have no effect; Exercise 6.1 develops that scalar case in detail.

6.9 Vanishing and Exploding Gradients

The long product of Jacobians is the source of the vanishing gradient problem (Bengio, Simard, and Frasconi 1994). Here \lVert\cdot\rVert denotes the Euclidean norm for vectors and its induced matrix norm, the spectral norm (the largest singular value). If each one-step Jacobian along the trajectory satisfies \lVert \operatorname{diag}(g'(\mathbf{z}_k))\,\mathbf{W}_{hh} \rVert \leq \kappa for some 0\leq\kappa < 1, the norm of the product is at most \kappa^{T-t}. This follows from submultiplicativity: the norm of a matrix product is at most the product of the matrix norms. For tanh, \lVert\mathbf W_{hh}\rVert<1 is a sufficient condition, since the activation derivatives lie between zero and one. For a fixed terminal loss, the gradient propagated to an early state is therefore multiplied by a geometrically small factor. When the remaining local derivative factors are bounded, early-step contributions to the parameter gradient can become numerically negligible.

For econometric forecasting, this is the central limitation of a plain RNN. Credit assignment means using the loss to determine how earlier state updates should change. Training can fail when this learning signal must cross a long time gap.

The same recurrent-state Jacobian product can also grow, in which case gradients explode rather than vanish. Since g' \leq 1 for the \tanh activation, each one-step Jacobian is bounded in norm by \lVert\mathbf{W}_{hh}\rVert, so \lVert\mathbf{W}_{hh}\rVert > 1 is necessary for this upper bound to permit exponential pathwise growth. It is not sufficient: whether the product actually grows depends on the entire trajectory of factors \operatorname{diag}(g'(\mathbf{z}_k))\,\mathbf{W}_{hh}. A per-factor bound below one forces decay, but individual factors with norms above one do not by themselves force growth. Nor does \lVert\mathbf{W}_{hh}\rVert\leq 1 uniformly bound every total parameter gradient, because contributions from many loss terms can still accumulate with sequence length.

In the scalar case, the pathwise picture is transparent: the product is \prod_{k=t+1}^{T} |W_{hh}|\,g'(z_k) and grows geometrically whenever the factors stay above some \gamma > 1 along the trajectory. Exploding gradients show up as numerical overflow or parameter updates that jump erratically between iterations, rather than as a silent failure to learn long-run dependence.

The standard remedy is gradient clipping (Pascanu, Mikolov, and Bengio 2013): if the norm of the stacked raw gradient vector \mathbf{v} exceeds a threshold c>0, replace \mathbf{v} by c\,\mathbf{v}/\lVert\mathbf{v}\rVert before the optimizer sees it. This transformation caps the raw gradient norm and preserves the raw gradient direction. Under plain gradient descent, it also caps the norm of the immediate parameter step, up to the learning rate; with momentum or adaptive optimizers, the eventual update also depends on stored optimizer state. Clipping stabilizes the exploding case but does nothing for vanishing gradients, whose problem is the loss of signal across a long credit-assignment path.

6.10 From One Series to Training Windows

The derivations above treat one sequence of length T with a single terminal loss. Estimation practice starts from something less tidy: one long time series of, say, N observations, from which the training sequences must first be constructed. Three choices—the window construction, the truncation of the gradient, and the decision to share parameters across time—deserve to be explicit, because each has an econometric interpretation and each reappears in the empirical chapter on networks for time series.

Windows as training observations. The standard construction cuts the series into overlapping fixed-length windows. With window length \tau, each forecast origin t=\tau,\ldots,N-1 contributes one training pair: the input sequence (\mathbf{x}_{t-\tau+1}, \ldots, \mathbf{x}_t) and the target y_{t+1}. Within each window, index the recurrence by a local step r=1,\ldots,\tau: step r receives \mathbf{x}_{t-\tau+r}. The local state starts at \mathbf{h}_0=\mathbf{0}, and the final local state \mathbf{h}_\tau produces the forecast at calendar origin t. Thus the state index inside a reset window counts steps from that window’s start, rather than dates from the start of the full series. The window diagram in the empirical chapter illustrates the distinction between the input history for one forecast and the observations used to estimate the model.

Temporal order matters within each window, but whole reset windows may be assigned to mini-batches in any order. One series of length N gives N-\tau training pairs when all inputs and targets are available. Consecutive windows share \tau-1 inputs, so their count is not a count of independent observations. Conditional on the realized training windows and fixed parameter values, however, a uniformly sampled mini-batch gives an unbiased gradient of the average empirical loss, by the sampling argument in Exercise 3.2 of the optimization chapter. This identity concerns randomness in batch selection. Overlap and serial dependence still matter for the statistical information in the sample and for forecast evaluation; the cross-validation chapter’s chronological train–validation–test discipline applies to forecast origins and target availability. A validation window may use earlier training-period observations as inputs; training must not use targets unavailable at the validation forecast origin.

Fixed windows and truncated backpropagation. Re-initializing the state at each window has a second effect: both the state recursion and the gradients run only across the \tau steps inside a window. It is worth separating two horizons that this fixed-window training scheme happens to tie together. The gradient horizon is how far back credit assignment reaches. Cutting the backward derivative chain after a fixed number of steps is truncated backpropagation through time (Williams and Peng 1990), and it caps the Jacobian products of the previous sections at length \tau no matter how long the series is. The state horizon is how far back the forward recursion carries information.

A state-carrying variant processes non-overlapping consecutive segments in chronological order, feeding the final state of one segment in as the initial state of the next. At each boundary it detaches the carried state: its numerical value is retained, but it is treated as a constant during the next segment’s backward calculation. The state horizon can therefore extend beyond \tau, while the gradient horizon cannot. Earlier inputs can still affect the forecast, but the next segment’s loss does not differentiate through the updates that produced the carried state. The shared weights still receive gradient contributions from their uses within the current segment.

Fixed-window training—the scheme used in the empirical chapter on networks for time series—truncates both horizons at \tau. Truncation reduces computation because the cost of a backward pass grows with sequence length. It may discard little additional usable gradient signal when contributions from earlier steps are already numerically negligible, but that negligibility is itself the vanishing-gradient problem rather than evidence that distant dependence is irrelevant.

With fitted parameters held fixed, a forecast from a reset window is a function of its inputs (\mathbf{x}_{t-\tau+1},\ldots,\mathbf{x}_t), including any engineered features supplied in them. It cannot use incremental predictive information contained only in observations before the window and not recoverable from those inputs. A moving average, cumulative return, or other summary placed in \mathbf{x}_t can carry older information into the window. The window length therefore plays the same role as the lag-window length L of the lagged FNN at the start of the chapter. Both networks can learn which supplied inputs matter: the FNN maps the lag vector directly to the output, while the RNN compresses the sequence through shared state updates. In both cases, the chosen window limits direct access to history.

Parameter sharing imposes time-homogeneous dynamics. Applying the same weights and biases at every step imposes the same state-update and output maps at every date. This is analogous to assuming a stable parametric structure when estimating an ARMA or GARCH model over a long sample. Stable conditional relationships can justify pooling windows from different periods, but do not guarantee enough information to estimate many weights: dependence, window overlap, and model complexity still matter. The inputs themselves need not be stationary, since time-invariance restricts the maps rather than the input distribution. A fixed map can also accommodate changing observed dynamics when its inputs or state encode the relevant regime. Structural breaks can cause misspecification when the changed relationship is not captured by those inputs or that state. Subsample estimation, rolling estimation windows, and predictors that describe the regime are possible responses.

Bridge to LSTM Networks

Plain RNNs are hard to train reliably whenever the forecast depends on information many recurrent steps in the past—precisely the long-run dependence case that motivates reaching for a recurrent model. Their value in this chapter is conceptual: they expose the structural problem that learning long-run dependence requires gradient signal across many time steps. LSTMs address this by modifying the state update with gates and a cell state that preserve information more reliably.

Where the implementation lives. This chapter deliberately stays at the conceptual level—recurrence, information sets, and gradient mechanics—without fitting a network in code. The empirical chapter on networks for time series provides the full Python workflow (sequence construction from a time series, chronological splits, training-only scaling, tuning, and evaluation) that applies directly to the recurrent models introduced here and in the next chapter.

6.11 Summary

Key Takeaways
  1. RNNs use shared parameters to update a hidden state that summarizes past inputs.
  2. Backpropagation through time applies the chain rule to the unrolled sequence of state updates.
  3. Repeated state transitions can attenuate or amplify gradients, making long-range learning difficult.
  4. Fixed windows limit the gradient horizon; forecasts can use earlier history only if the window’s inputs carry it.
Common Pitfalls
  • Hidden-state coordinates do not automatically correspond to identified economic states.
  • A deterministic RNN output is not a full predictive distribution without a probabilistic output model.
  • Keep observations ordered within windows and keep future targets out of the training split.
  • Gradient clipping limits large gradients but does not repair vanishing gradients.

6.12 Exercises

Exercise 6.1: Vanishing Gradient Problem in RNNs

Consider a scalar RNN with fixed initial state h_0=0:

\begin{aligned} z_t &= W_{hh}h_{t-1}+W_{xh}x_t+b_h, \\ h_t &= \tanh(z_t), \\ \hat y_{t+1\mid t} &= W_{hy}h_t+b_y. \end{aligned}

Let L_T=\ell(y_{T+1},\hat y_{T+1\mid T}) be a differentiable terminal loss. In Parts 1–2, hold the observed sequence, terminal date T, and fitted parameter values fixed, and assume \partial L_T/\partial h_T is finite.

  1. Derive the scalar BPTT gradient. Express \partial L_T/\partial W_{hh} as a sum of contributions from the repeated uses of W_{hh}. Evaluate the local derivative of h_t with respect to W_{hh}, holding h_{t-1} fixed, and express \partial h_T/\partial h_t as a product of one-step derivatives.
  2. Bound contributions from earlier steps. Prove that |\partial h_T/\partial h_t|\leq|W_{hh}|^{T-t} and use h_0=0 and the range of tanh to bound each summand from Part 1. Explain what |W_{hh}|<1 implies for contributions across long time gaps, and why it does not require the total parameter gradient to vanish.
  3. Compare local and delayed signals. Assume finite second moments and squared loss at each forecast origin. For an observed first-order autoregressive (AR(1)) process, the RNN receives x_t=y_t, a realization of Y_t, and the conditional mean of Y_{t+1} given the process’s history is \phi Y_t, with |\phi|<1. In a delayed-signal task, the only inputs are realizations x_s of nondegenerate independent and identically distributed variables X_s, and the conditional mean of Y_{t+1} given (X_s:s\leq t) is \psi X_{t-d}, with \psi\ne0 and d\geq1. For t\geq d+1, assume the relevant input has not been discarded by a state reset. Trace its path to \hat y_{t+1\mid t} in each task and count the recurrent transitions. Which task requires a learning signal across a long time gap, and why does \phi close to one not by itself create that requirement?

Exam level, approximately 20–25 minutes. The three parts cover the gradient calculation, its contraction bound, and the forecasting interpretation.

Hint for Part 1

Temporarily regard the recurrent weight at each time step as a separate copy. Differentiate with respect to each copy, holding that step’s previous state fixed, then add the contributions because the copies share one parameter.

Hint for Part 3

Locate the input that determines the conditional mean. Count recurrent transitions after that input enters the hidden state; the future date of the forecast target does not itself add a recurrent transition.

Solution

Part 1: Scalar backpropagation through time

The local weight derivative and the state sensitivity are

\begin{aligned} \left.\frac{\partial h_t}{\partial W_{hh}}\right|_{h_{t-1}\,\mathrm{fixed}} &= \tanh'(z_t)h_{t-1}, \\[0.5em] \frac{\partial h_T}{\partial h_t} &= \prod_{k=t+1}^{T} W_{hh}\tanh'(z_k), \end{aligned}

because each one-step state derivative is W_{hh}\tanh'(z_k). The empty product equals one when t=T. Applying the chain rule to every use of the shared weight gives

\frac{\partial L_T}{\partial W_{hh}} = \sum_{t=1}^{T} \frac{\partial L_T}{\partial h_T} \frac{\partial h_T}{\partial h_t} \tanh'(z_t)h_{t-1}.

The local factor holds h_{t-1} fixed; the dependence of that state on earlier uses of W_{hh} is already included in the other summands. Including it again would double-count paths.

Part 2: Geometric attenuation

Since 0\leq\tanh'(z)=1-\tanh^2(z)\leq1,

\begin{aligned} \left|\frac{\partial h_T}{\partial h_t}\right| &= \prod_{k=t+1}^{T}|W_{hh}|\tanh'(z_k) \\ &\leq |W_{hh}|^{T-t}. \end{aligned}

Also, h_0=0 and subsequent states are tanh outputs, so |h_{t-1}|\leq1 and the local weight derivative has magnitude at most one. The absolute value of the t-th summand is therefore bounded by

\left|\frac{\partial L_T}{\partial h_T}\right|\,|W_{hh}|^{T-t}.

The terminal loss derivative is a common finite factor under the stated fixed-sequence convention. If |W_{hh}|<1, the bound is geometrically smaller for earlier steps, weakening the learning signal across long gaps. Recent-step contributions need not be small, so the sum of all contributions need not vanish.

Part 3: Local versus delayed prediction

Under squared loss, the optimal forecast is the conditional mean of Y_{t+1}. In the AR(1) task, observing the current input x_t=y_t supplies all the information needed for the optimal forecast \phi y_t. Its path is x_t\to h_t\to\hat y_{t+1\mid t}, with zero recurrent transitions after the input enters the state. A coefficient close to one makes the observed series persistent, but the stipulated conditional mean still depends only on the current observation.

In the delayed task, the relevant input is x_{t-d}. The intermediate inputs do not reveal it because the inputs are independent. Its path is x_{t-d}\to h_{t-d}\to\cdots\to h_t\to\hat y_{t+1\mid t}, crossing d recurrent transitions. The state-sensitivity factor along this path is bounded by |W_{hh}|^d. When |W_{hh}|<1, this factor attenuates the learning signal from the delayed input, even though the forecast itself is only one step ahead.

Exercise 6.2: Manual RNN Forward Pass

Consider the simple RNN shown in Figure 6.2: a single hidden unit processing a sequence of length 3, with hidden update h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h) and linear output \hat{y}_{t+1\mid t} = W_{hy} h_t + b_y (identity output activation).

The parameters are:

  • Weight for input-to-hidden: W_{xh} = 0.5
  • Weight for hidden-to-hidden: W_{hh} = 0.8
  • Bias for hidden unit: b_h = 0.1
  • Weight for hidden-to-output: W_{hy} = 1.2
  • Bias for output: b_y = 0.0

The input sequence is (x_1, x_2, x_3) = (0.2, -0.5, 0.3) and the initial hidden state is h_0 = 0. Use the approximations \tanh(0.2) \approx 0.197, \tanh(0.008) \approx 0.008, and \tanh(0.256) \approx 0.251. For Part 3, also use \tanh(-0.15) \approx -0.149 and \tanh(0.131) \approx 0.130.

  1. Compute the forward pass. For t = 1, 2, 3, compute the hidden state h_t and the output \hat{y}_{t+1\mid t}.
  2. Separate value from sensitivity. Using your results from Part 1, show numerically how the memory term W_{hh} h_1 and the bias b_h offset the input contribution at t=2. Then compute the sensitivity \partial h_2/\partial x_1 and state what the value of h_2 does and does not imply about the memory of x_1, connecting your answer to the geometric decay factor from Exercise 6.1.
  3. Compare reset and detachment. Set \tau=2. Evaluate all forecasts and derivatives at the supplied parameter values. For the forecast \hat y_{4\mid3}, compare (a) resetting to zero before processing the window (x_2,x_3) and (b) carrying h_2 from Part 1 into a final, shorter segment containing only x_3, with h_2 detached at the boundary. Under (a), state which inputs the forecast can use, compute \hat y_{4\mid3}, and find \partial\hat y_{4\mid3}/\partial x_1. Under (b), use Part 2 to compute the derivative of the forecast with respect to x_1 through the full forward recursion, then explain which backward paths detachment removes and why the forecast’s derivative with respect to W_{hh} retains a step-3 contribution. Finally, state in one sentence why neither scheme by itself resolves a structural break that is not represented in the inputs or state.

Exam level, approximately 20–25 minutes. Part 1 checks the recursion, Part 2 separates state value from sensitivity, and Part 3 compares the effects of resetting and detaching the state.

Hint for Part 2

For the sensitivity, apply the chain rule along x_1 \to h_1 \to h_2 and recall that \tanh'(z)=1-\tanh^2(z).

Hint for Part 3

Under (b), the forecast’s dependence on x_1 runs through h_2. Multiply the Part 2 sensitivity by the step-3 state derivative and the output weight. Detachment changes what the backward pass differentiates, while preserving the carried state’s numerical value.

Solution

Part 1: Forward pass

At t = 1:

\begin{aligned} h_1 &= \tanh(0.8 \cdot 0 + 0.5 \cdot 0.2 + 0.1) \\ &= \tanh(0.2) \approx 0.197, \\[0.5em] \hat{y}_{2\mid 1} &= 1.2 \cdot 0.197 \approx 0.236 \end{aligned}

At t = 2:

\begin{aligned} h_2 &= \tanh(0.8 \cdot 0.197 + 0.5 \cdot (-0.5) + 0.1) \\ &= \tanh(0.158 - 0.25 + 0.1) \\ &= \tanh(0.008) \approx 0.008, \\[0.5em] \hat{y}_{3\mid 2} &= 1.2 \cdot 0.008 \approx 0.010 \end{aligned}

At t = 3:

\begin{aligned} h_3 &= \tanh(0.8 \cdot 0.008 + 0.5 \cdot 0.3 + 0.1) \\ &= \tanh(0.006 + 0.15 + 0.1) \\ &= \tanh(0.256) \approx 0.251, \\[0.5em] \hat{y}_{4\mid 3} &= 1.2 \cdot 0.251 \approx 0.301 \end{aligned}

Part 2: A near-zero state value is not the same as lost memory

At t = 2, the input contribution W_{xh} x_2 = 0.5 \times (-0.5) = -0.25 is almost exactly offset by the memory term W_{hh} h_1 = 0.8 \times 0.197 = 0.158 plus the bias b_h = 0.1, giving a pre-activation near zero and thus h_2 \approx 0. This is cancellation: two sizable contributions of opposite sign happen to sum to nearly zero.

Cancellation of the value does not mean the memory of x_1 is gone. Memory in the gradient sense is the sensitivity

\begin{aligned} \frac{\partial h_2}{\partial x_1} &= \underbrace{\tanh'(z_2)\, W_{hh}}_{\partial h_2/\partial h_1} \cdot \underbrace{\tanh'(z_1)\, W_{xh}}_{\partial h_1/\partial x_1} \\[0.5em] &\approx (1.000 \times 0.8) \times (0.961 \times 0.5) \\ &\approx 0.3844 \approx 0.38, \end{aligned}

using \tanh'(z) = 1 - \tanh^2(z) with z_1 = 0.2 and z_2 = 0.008. A sensitivity of 0.38 after one recurrence step is substantial—in fact, because z_2 \approx 0 places \tanh in its steepest region, h_2 is close to maximally sensitive to perturbations of h_1. Had x_1 been slightly different, h_2 would have been noticeably different: the state still remembers x_1 even though its value happens to sit near zero.

The genuine connection to Exercise 6.1 runs through the rate of decay, not the value of the state. Each additional recurrence step multiplies the sensitivity by at most W_{hh}\,\max_z \tanh'(z) = 0.8, so the influence of x_1 fades geometrically over many steps (0.8^{10} \approx 0.11, 0.8^{30} \approx 0.001). The two-part conclusion: after one step, the memory of x_1 is still strong despite the near-zero state value; over long horizons, it is the geometric factor from Exercise 6.1—not value cancellation—that makes plain RNNs forget.

Part 3: Reset versus detachment

Under scheme (a), the reset forecast uses only x_2 and x_3. Write \tilde h_r for its state after local window step r, with \tilde h_0=0: step 1 processes x_2 and step 2 processes x_3. The reset forward pass is

\begin{aligned} \tilde h_1 &= \tanh(0.8\cdot0+0.5\cdot(-0.5)+0.1) \\ &= \tanh(-0.15) \approx -0.149, \\[0.5em] \tilde h_2 &= \tanh(0.8\tilde h_1+0.5\cdot0.3+0.1) \\ &\approx \tanh(0.131) \approx 0.130, \\[0.5em] \hat y_{4\mid3} &= 1.2\tilde h_2 \approx 0.156. \end{aligned}

The reset forecast is about 0.156, compared with 0.301 when carrying the state from Part 1: the same parameters and last two inputs give different forecasts because the initial states differ. With the parameters fixed and no engineered input carrying x_1, the reset forecast has no dependence on x_1, so \partial\hat y_{4\mid3}/\partial x_1=0.

Under scheme (b), carrying h_2 preserves the forward pass from Part 1. The forecast can depend on all three inputs. Differentiating through the full forward recursion, including how the carried state was produced, gives

\begin{aligned} \frac{\partial\hat y_{4\mid3}}{\partial x_1} &= W_{hy}\tanh'(z_3)W_{hh} \frac{\partial h_2}{\partial x_1} \\ &\approx 1.2(1-0.251^2)\times0.8\times0.3844 \\ &\approx 0.346. \end{aligned}

The extra recurrent transition and the output weight distinguish this sensitivity from \partial h_2/\partial x_1\approx0.38 in Part 2.

Detaching h_2 leaves its value unchanged but removes the backward paths through its construction. Thus the truncated graph gives no gradient back to x_1 or the step-1 and step-2 uses of W_{hh}. The step-3 use still contributes to the forecast derivative:

\begin{aligned} \left.\frac{\partial\hat y_{4\mid3}}{\partial W_{hh}}\right|_{h_2\,\mathrm{fixed}} &= W_{hy}\tanh'(z_3)h_2 \\ &\approx 1.2\times0.937\times0.008 \\ &\approx 0.009. \end{aligned}

The local factor is small because it scales with the state value h_2, which is near zero by the cancellation in Part 2. The input sensitivity above instead contains the derivative \partial h_2/\partial x_1, which need not be small when h_2 is near zero. The corresponding loss-gradient contribution also includes the derivative of the loss with respect to the forecast. A zero gradient through the detached boundary therefore does not mean that the forward forecast has forgotten x_1.

Neither scheme by itself resolves an unrepresented structural break, because both reuse the same parameters across dates and can therefore fit a compromise poorly suited to either regime.
